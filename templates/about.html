About LaptopScout

A Content-Based Laptop Recommendation System using Feature Engineering, Normalization, and Cosine Similarity.

How the Algorithm Works

LaptopScout uses a hybrid content-based recommendation system that combines feature normalization, cosine similarity, and purpose-weighted scoring to suggest the most relevant laptops for each user.

  1. Hard Filtering: Laptops outside the user's stated budget are strictly excluded. Minimum RAM is enforced as a hard constraint. Other preferences (brand, SSD, processor family, graphics, OS) are applied as soft filters — they tighten the pool but never leave it empty.
  2. Feature Normalization: The remaining laptops' numerical features (price, spec_score, RAM, SSD, CPU cores) are normalized using MinMaxScaler to bring all values into a 0–1 range for fair comparison.
  3. Cosine Similarity: A synthetic ideal user vector is constructed from the user's requirements (target budget, desired RAM, SSD, max cores). The system calculates cosine similarity between this ideal vector and every laptop's normalized feature vector to measure closeness of fit.
  4. Purpose-Based Weights: Depending on the user's stated purpose (Gaming, Programming, Student, ML, etc.), a configurable weight table amplifies the features most relevant to that use case. For example, Gaming weights GPU and CPU heavily; Student weighs price efficiency most.
  5. Hybrid Final Score: The four component scores are blended into a single recommendation score:
    final_score = preference_score × 0.35 + performance_score × 0.25 + value_score × 0.20 + purpose_score × 0.20 Scores are scaled to a display range of 65–97% to represent realistic confidence levels.
  6. Category Identification: The top laptop by final_score becomes Best Match; by value_score becomes Best Value; by performance_score becomes Best Performance.

Dataset

The recommendation engine is powered by a curated dataset of real-world laptop specifications sourced from e-commerce listings. Key fields used:

  • Model name & Brand
  • Processor name
  • RAM (GB), SSD (GB), HDD (GB)
  • Graphics card
  • Screen size & Resolution
  • Operating System
  • Number of cores & threads
  • Spec score & Price (₹)

No data is fabricated or estimated — all displayed specifications come directly from the dataset.

Key Features
  • Smart budget-aware filtering
  • Purpose-adaptive scoring (8 use cases)
  • Three recommendation categories: Best Match, Best Value, Best Performance
  • Model variant grouping — same laptop, different configs
  • Side-by-side comparison of up to 3 laptops
  • Cheaper & better-performance alternatives
  • Automatic pros & cons from dataset values
  • Dynamic "Why this laptop?" explanation
  • Save to browser localStorage
  • Live search across model name, brand, processor & GPU
Scoring Components
Component Weight What it measures
Preference Score 35% How closely specs match user requirements + cosine similarity
Performance Score 25% Spec score, RAM, SSD, cores, GPU tier
Value Score 20% Performance per price unit (normalized)
Purpose Score 20% Use-case weighted blend (GPU, CPU, RAM, price)
