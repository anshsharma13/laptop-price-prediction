# Smart Laptop Recommendation System (Flask + Machine Learning)

## What it does
A beginner-friendly full-stack ML project that recommends laptops based on user inputs like budget, purpose, RAM, SSD requirement, GPU needs, screen size, etc.

- **ML algorithm:** Decision Tree (primary)
- **Optional comparison:** Random Forest

## Folder structure
```
smart-laptop-recommender/
  app.py
  train_model.py
  model.pkl                # generated by train_model.py
  dataset.csv              # place your Kaggle dataset here
  prediction_history.db   # generated at runtime
  requirements.txt
  README.md
  templates/
    index.html
    form.html
    result.html
    about.html
  static/
    styles.css
```

## Setup
1. Put your Kaggle laptop dataset into:
   `smart-laptop-recommender/dataset.csv`

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Train the model:
```bash
python train_model.py
```
This will create `model.pkl`.

4. Run Flask:
```bash
python app.py
```
Open: http://127.0.0.1:5000

## How recommendation works (high level)
1. The app loads the trained model bundle.
2. It filters candidate laptops using the user constraints (brand, min RAM, SSD required, GPU preference, etc.).
3. It scores candidates using the ML model.
4. It returns:
   - Best matching laptop
   - Top 3 alternatives
   - A confidence score (relative normalization)
   - “Why recommended” explanation (human-readable heuristics)
   - Performance score cards

## Deployment
For deployment, you can switch from `app.run(debug=True)` to a production WSGI server like Gunicorn.
